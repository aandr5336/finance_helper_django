# Висновок до розділу 1

У розділі реалізовано вебзастосунок BudgetFlow на Django з СУБД MySQL 8. Спроєктовано й описано схему даних (ERD у MySQL Workbench, SQL-скрипти діалекту MySQL), реалізовано моделі предметної області, CRUD транзакцій на Generic Views, дашборд і ролі доступу. Контрольний приклад проходить від автентифікації до аналітики та перевірки даних у Workbench, що підтверджує узгодженість програмної реалізації зі схемою БД і готує матеріал до розділу тестування.
